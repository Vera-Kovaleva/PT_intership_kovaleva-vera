# Тестовое задание

## В качестве выполненного задания ожидаем:

1. Ссылка на GitHub репозиторий.
2. README.md с понятными инструкциями по запуску проекта, архитектурой решения, описанием выбора ключевых технологий и результаты оценки качества. Обязательно должен быть docker compose file, подняв который должно запуститься рабочее приложение.

## Задача

Детали реализации на усмотрение кандидата.

Реализуйте HTTP-сервер с двумя endpoint'ами:

### POST /shorten

Принимает:

```json
{
    "url": "https://example.com"
}
```

Возвращает:

```json
{
    "short_url": "http://localhost:8080/abc123"
}
```

### GET /{code}

Редиректит на оригинальный URL
