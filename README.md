# URL Shortener

HTTP-сервис сокращения ссылок: принимает длинный URL и выдаёт короткий код, по коду перенаправляет на исходный адрес.

## О задании

Тестовое задание для стажировки в Positive Technologies. По условию нужен HTTP-сервер с двумя эндпоинтами: `POST /shorten` принимает JSON со ссылкой и возвращает короткую, `GET /{code}` редиректит на оригинальный URL. Детали реализации оставлены на усмотрение кандидата.

Исходное задание — [docs/00_task.md](docs/00_task.md).

## Документация

**[docs/01_requirements.md](docs/01_requirements.md) — что система делает.** Возможности пользователей, политика допустимых ссылок, полный контракт успешных ответов и ошибок с обоснованием каждого статуса, идемпотентность, правила нормализации URL, инварианты данных, перечень обязательных тест-сценариев, границы скоупа.

**[docs/02_design.md](docs/02_design.md) — как она это делает.** Архитектура, схема БД и почему дедупликация идёт по хешу, генерация кода и обработка коллизий, зарезервированные коды, таймауты и их иерархия, отображение ошибок в ответы, логирование, безопасность, тестирование, требования к Dockerfile и compose, порядок сборки и запуска.

Документы связаны: требования не содержат технических решений, дизайн не вводит возможностей, которых нет в требованиях.
